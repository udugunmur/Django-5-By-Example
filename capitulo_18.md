# Otros libros que podrías disfrutar

Si disfrutaste de este libro, tal vez te interesen estos otros libros de Packt:

## Responsive Web Design with HTML5 and CSS - Fourth Edition

**Ben Frain**  
ISBN: 9781803242712

- Utilizar consultas de medios (*media queries*), incluida la detección táctil/ratón y preferencias de color.
- Aprender la semántica de HTML y crear marcado accesible.
- Facilitar diferentes imágenes según el tamaño de la pantalla o la resolución.
- Escribir las funciones de color más recientes, mezclar colores y elegir los más accesibles.
- Utilizar archivos SVG en diseños para proporcionar imágenes independientes de la resolución.
- Crear y utilizar propiedades personalizadas de CSS, haciendo uso de nuevas funciones de CSS, incluidas `clamp`, `min` y `max`.
- Añadir validación y elementos de interfaz a formularios HTML.
- Mejorar los elementos de interfaz con filtros, sombras y animaciones.

## React and React Native - Fifth Edition

**Mikhail Sakhniuk**  
ISBN: 9781805127307

- Explorar la arquitectura de React, las propiedades de los componentes (*props*), el estado y el contexto.
- Trabajar con React Hooks para gestionar funciones y componentes.
- Obtener datos de un servidor utilizando la API Fetch, GraphQL y WebSockets.
- Profundizar en las estrategias de gestión del estado interno y externo.
- Construir interfaces de usuario robustas para aplicaciones móviles y de escritorio utilizando Material-UI.
- Simplificar el diseño de la interfaz para aplicaciones React Native utilizando kits de interfaz de usuario.
- Gestionar el rendimiento de la aplicación con renderizado del lado del servidor (*server-side rendering*), componentes diferidos (*lazy components*) y Suspense.
